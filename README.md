# 譜面補正

スキャンしたPDFや画像フォルダの傾きと上下を、PC内で補正します。

## 起動

Python 3.10以上が必要です。Windows では x64 版の Python を使ってください。PDF の処理に使うライブラリも `pip` で入ります。

`app.py` のあるフォルダで、OS に合ったコマンドを実行します。

### macOS（ターミナル）

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

### Windows（PowerShell）

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

ブラウザで [http://127.0.0.1:8765](http://127.0.0.1:8765) を開きます。画像フォルダの保存には Edge または Chrome を使用してください。停止するには起動した端末で Ctrl+C を押します。

## 使い方

1. PDFを画面にドラッグ＆ドロップするか、「PDFを選ぶ」を押します。画像は「画像フォルダを選ぶ」で開き、フォルダ内の相対パス順に並べます（例 `page2.png`、`page10.png`）。
2. 表紙・白紙を含む読み込み順で、奇数ページ（1・3・5…）を180°回転します。ページごとに回転を解除できます。正しい向きで五線と小節線の傾き（°）を計測し、五線を水平にした後、小節線に残る傾きを補正します。180°回転だけを適用したいページは「傾きも補正」のチェックを外せます。計測や判定が難しい箇所は「要確認」と表示します。「端の白塗りを調整」では、表示中の向きに合わせて上下左右の幅を入力できます。
3. 「補正結果を保存」または Ctrl+S（Mac は ⌘+S）を押します。PDFの保存名はプレビュー上の「保存ファイル名」で変更できます。画像の場合は選択した保存先の下に新しいフォルダを作ります。

ノートPCでは「全体」表示でページを確認し、細部は `+` で拡大できます。左右キーで前後のページに移動し、`[` / `]` で角度を0.01°ずつ変えます。全ショートカットは画面上部の「キー操作」または `?` で確認できます。

PDFは300 dpiの画像として書き出し、表示上のページ寸法を維持します。検索可能な文字や注釈の編集情報は画像化されます。画像はファイル名・拡張子・ピクセル寸法を維持します。JPEG、PNG、単一フレームのTIFF、BMP、WebPに対応します。傾きを補正するときは、必要に応じて画像を縮小し、端の欠けを防ぎます。

処理はローカルで完結します。Gitの追跡対象はプログラムの明示的なファイル一覧に限定しています。

音部記号の照合画像には Steinberg の [Bravura](https://github.com/steinbergmedia/bravura) を使用しています。[SIL Open Font License 1.1](score-assets/OFL.txt)

裏写り補正は調整パネルで0〜100の強さを指定します。指定した明るさ以上の部分を完全な白に置き換えます。強さを上げると、より濃い裏写りまで除去します。初期値は0です。強さはページごとに保存され、全ページにも適用できます。
